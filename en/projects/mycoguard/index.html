01 Problem

Wild mushroom foraging poses real public-health risks, yet most consumer "identification" tools answer with false certainty — a single wrong "safe" call can be dangerous.

The app must work offline for field use and must communicate uncertainty honestly.

02 Approach

Two signal paths: a deterministic offline rule engine with live SVG morphology rendering, and photo recognition via Qwen-VL. Both feed a single uncertainty-calibrated output.

A safety-knowledge RAG module answers follow-up questions with cited sources; every screen carries a disclaimer and confidence tier (low / medium / high / cannot judge).

03 Architecture
◫ Architecture diagram — photo → Qwen-VL recognition + offline rule engine → uncertainty calibration → safety verdict + RAG citations.
04 Highlights
  • Offline rule engine + SVG real-time morphology rendering
  • Calibrated uncertainty tiers, never absolute claims
  • Safety RAG Q&A with citations
  • Site-wide medical disclaimers
05 Results
  • Rule engine emits only calibrated uncertainty (low / medium / high / cannot judge) with a 97% confidence ceiling; <3 traits forces "cannot judge"; absolute edible/poisonous language is forbidden by tests.
  • 26 curated safety-knowledge entries with per-entry sources; vision recognition via qwen-vl-plus with graceful offline degradation (verified in a real end-to-end smoke run).
