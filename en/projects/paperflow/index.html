01 Problem

Reading the literature is a bottleneck: a single paper link or PDF has to become a structured review, related-work links and next-step suggestions — manually this takes hours.

Reinforces the multi-agent research direction of the Werewolf paper: role-specialized agents that plan, read, critique and synthesize.

02 Approach

A lightweight self-built orchestration layer: Researcher fetches metadata via the free arXiv API, Reader extracts claims, Critic challenges them, Synthesizer merges into a structured report.

DeepSeek function calling drives tool use; a JSON task board keeps the team’s progress inspectable and reproducible.

03 Architecture
04 Highlights
  • Self-built multi-agent orchestration (no heavy framework)
  • Free arXiv API integration with Crossref fallback
  • DeepSeek function calling + JSON task board
  • Structured review + related-work survey output
05 Results
  • Two archived end-to-end runs: the author’s Werewolf paper (DOI + local PDF) with every claim paired to a verbatim quote verified against the paper text, and related-work links resolved to real arXiv IDs; a second run through Attention Is All You Need exercises the full arXiv pipeline (BLEU 28.4/41.8 correctly restated) with relevance scored 4/10 against an explicit rubric.
  • Self-built orchestration with an inspectable JSON task board; graceful degradation to abstract-only review when full text is unavailable.
06 Demo

Live recording of a real run: submit the author’s Werewolf paper DOI → the four-agent team (Researcher → Reader → Critic → Synthesizer) executes with visible task-board states → structured review with fact-checked claims.
