02 Problem

Manual invoice review for reimbursement and audit is slow, error-prone and hard to scale: clerks re-key fields, duplicate invoice numbers slip through, and arithmetic or tax-rate inconsistencies are caught only by chance.

Existing OCR tools extract text but not structure, and provide no confidence signal or audit logic on top.

03 Approach

Qwen-VL multimodal document understanding produces structured JSON fields with per-field confidence; a layered FastAPI service orchestrates extraction, normalization and audit.

A declarative rule-audit engine detects duplicate invoice numbers, arithmetic inconsistencies, abnormal tax rates and buyer/seller mismatches, then visualizes the document relationships as a knowledge graph.

04 Architecture
05 Highlights
  • Structured field extraction with per-field confidence signals
  • Declarative rule engine: duplicate / arithmetic / tax anomalies
  • Interactive knowledge-graph explorer — object filters, node focus, transaction legend
  • Invoice detail drawer: confidence bars, audit evidence, graph connections
  • Audit statistics charts (by rule / by severity)
06 Results
  • Real-API benchmark over 30 synthetic invoices (qwen-vl-plus): 82.5% overall field-level accuracy — invoice number 86.7%, date 90.0%, party names 86.7%, amounts 80–86.7%, tax IDs 70–72% (hardest field); average confidence ~0.97; 3/30 file-level failures recorded.
  • 8 audit rules with severity ranking and evidence — including QR-code cross-validation (invoice number / amounts decoded from the invoice QR and checked against the extracted fields) and GB 32100-2015 tax-ID check-digit repair; the 30-invoice demo batch with injected anomalies produces exactly matched findings.
  • An offline evaluation harness with a machine-readable ground-truth benchmark; model choice, DPI and retry policy are backed by measured evidence.
07 Tech stack

  • Vision: Qwen-VL multimodal document understanding
  • Frontend: React · TypeScript dashboard
  • Data: knowledge graph + field-level evaluation harness
