Measured results

  • Six-configuration retrieval ablation on one shared candidate pool per query (strict section-level hit@1), on an evaluation set rebuilt so that it can falsify something: 102 rows, 87 answerable plus 15 unanswerable, with difficulty strata and multi-hop items whose answers must all be found.
  • The rebuilt set overturned the previous set's conclusion. Dense-only scores 0.908, hybrid 0.851, hybrid + rerank 0.874 — so the reranker is now BEHIND dense-only overall, its gain confined to the single-fact stratum (0.910 vs 0.895) while it loses 0.333 on cross-section questions (0.667 vs 1.000). The old set had 44 of 50 rows answerable from a single section, so the harder strata were unmeasurable: the earlier "reranking helps" reading was an artefact of an easy benchmark.
  • Multi-hop items are reported two ways because the honest one is unflattering: hit@k accepts any gold section, so cross-section hit@1 reads a perfect 1.000 — but requiring all gold sections gives 0.214-0.357, and the zero-content title-only baseline (0.429) beats every real configuration. A retrieval number also only means as much as the index behind it: per-section accounting had found 16% of the corpus was never indexed (retention 0.848 to 0.995 after the fix), and this ablation was re-run on the rebuilt index.
  • Refusal was the clearest product gap, and it is now closed and re-measured rather than assumed. Prompt-only, the model refused 3 of 15 unanswerable questions and answered the other 12 from chunks that do not contain the answer. The shipped retrieval-side gate refuses 13 of 15 at 2.3% false refusals in-sample — and 6.9% out-of-sample under a grouped 5-fold refit, which is the number to quote. The gate costs nothing to run (0.04 ms), makes refused requests 20x faster (0.09 s vs 2.06 s) and removes their generation calls entirely: 27 generation calls became 14, halving spend on the same 27 questions.
  • Two things about that gate are worth stating precisely. Its threshold is fitted on one textbook and is therefore in-sample; both operating points are published (the conservative 5%-false-refusal budget ships, the aggressive Youden point does not), and a test re-reads the calibration artifact so the constant cannot drift. And every false refusal turned out to have the correct section already at retrieval rank 1 — the score measures topic similarity, not answerability, so the failing cases are "retrieved the right page but the page does not answer the question".
  • Local BGE-M3 embeddings — zero API cost for retrieval; DeepSeek generates cited answers with source highlighting. A deterministic citation screen flags unsupported citations rather than asserting the answer is grounded.
