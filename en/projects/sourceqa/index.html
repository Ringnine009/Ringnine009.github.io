SourceQA

Cited Q&A over open textbooks: BGE-M3 embeddings, hybrid retrieval, DeepSeek generation with per-source citations — plus a retrieval ablation that reports its own baselines.

Feature walkthrough

  • Declines instead of guessing — a retrieval-side gate refuses when the textbook does not support the question, and shows its own score against the threshold
  • Local BGE-M3 embeddings — zero embedding API cost
  • Retrieval ablation with the baselines that reframe it
  • Retrieval breakdown panel — dense / BM25 / RRF scores per source
  • Conversation history persisted in the browser
  • Cited answers traceable to source chunks

Measured results

  • Retrieval ablation on one shared candidate pool per query (strict section-level hit@1): 102 rows, 87 answerable + 15 unanswerable, with difficulty strata and multi-hop items.
  • The rebuilt set overturned the previous conclusion: dense-only 0.908, hybrid 0.851, hybrid + rerank 0.874 — so the reranker is now behind dense-only overall.
  • Its gain is confined to the single-fact stratum (0.910 vs 0.895), and it loses 0.333 on cross-section questions (0.667 vs 1.000); the old set had 44 of 50 rows answerable from one section.
  • Multi-hop items are reported two ways: hit@k accepts any gold section, so cross-section hit@1 reads a perfect 1.000, but requiring all gold sections gives 0.214-0.357.
  • The zero-content title-only baseline (0.429) beats every real configuration, and the index was rebuilt after per-section accounting found 16% of the corpus never indexed (retention 0.848 → 0.995).
  • Prompt-only, the model refused 3 of 15 unanswerable questions and answered the other 12 from chunks that do not contain the answer; the shipped retrieval-side gate refuses 13 of 15.
  • The gate’s false refusals are 2.3% in-sample and 6.9% out-of-sample (grouped 5-fold refit) — quote the latter; it costs 0.04 ms and cuts generation calls from 27 to 14.
  • It makes refused requests 20x faster (0.09 s vs 2.06 s) at zero cost to run, and the threshold is fitted on one textbook, so it is in-sample.
  • Both operating points are published (the conservative 5%-false-refusal budget ships, the aggressive Youden point does not), and a test re-reads the calibration artifact so the constant cannot drift.
  • Every false refusal already had the correct section at retrieval rank 1 — the score measures topic similarity, not answerability.
  • Local BGE-M3 embeddings — zero API cost for retrieval; DeepSeek generates cited answers with source highlighting, and a deterministic citation screen flags unsupported citations.
