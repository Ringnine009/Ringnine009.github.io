Cited Q&A over open textbooks with hybrid retrieval

01 Problem

Students ask questions against open textbooks, but generic chatbots hallucinate because they cannot ground answers in the actual source material.

Answers must be verifiable: every claim should point back to a chunk of the book.

02 Approach

Full RAG pipeline: parse PDF chapters, chunk with structure awareness, embed locally with BGE-M3 (zero API cost), store in ChromaDB, and retrieve with hybrid dense + BM25 scoring.

BGE-reranker re-scores candidates; DeepSeek generates cited answers; a retrieval-evaluation set (hit-rate + answer quality) tracks regressions.

03 Architecture
◫ Architecture diagram — PDF → parser → chunks → BGE-M3 → ChromaDB → hybrid retriever → reranker → DeepSeek → cited answer → chat UI.
04 Highlights
  • Local BGE-M3 embeddings — zero embedding API cost
  • Hybrid retrieval: dense + BM25, then BGE rerank
  • Cited answers traceable to source chunks
  • Retrieval + answer-quality evaluation set
05 Results
  • Retrieval benchmark on a 50-question eval set over 165 D2L sections (3,439 chunks): hybrid (dense + BM25 + BGE-reranker) reaches hit@1 1.000 / hit@3 1.000 — +2 pts over dense-only and +16 pts over BM25-only, confirming lexical–semantic complementarity; reranking adds 4 pts at 620ms/query on GPU.
  • Answer quality: 12 questions sampled and human-scored at 4.92/5; SSE streaming with cited sources verified end-to-end (e.g., LSTM questions hit the LSTM chapter).
  • Local BGE-M3 embeddings — zero API cost for retrieval; DeepSeek generates cited answers with source highlighting.
