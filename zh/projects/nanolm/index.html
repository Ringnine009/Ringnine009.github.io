01 问题

生产级 LLM 应用容易演示但难理解：模型本身是黑盒。从零实现让全栈——分词、注意力、训练动态——变得可读。

离线、零 API 成本的聊天是真实需求（例如 MycoGuard 的离线层）。

02 方法

用 PyTorch 从零实现 decoder-only GPT 风格 transformer——BPE 分词、数据管线、transformer 模块、训练循环与采样。

小语料预训练后，在 8GB 笔记本 GPU 上 QLoRA 微调 Qwen2.5-1.5B；FastAPI 流式推理 + 聊天 UI。
