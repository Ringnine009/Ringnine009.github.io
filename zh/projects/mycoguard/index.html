MycoGuard

01 问题

野外采蘑菇存在真实的公共健康风险，而多数消费级“识别”工具给出过度自信的结论——一次错误的“安全”判断可能造成危险。

应用需支持野外离线使用，并诚实地表达不确定性。

02 方法

双信号通路：确定性离线规则引擎 + SVG 实时形态渲染，以及 Qwen-VL 拍照识别；两者汇入统一的不确定性校准输出。

安全知识 RAG 模块以带引用的方式回答追问；每个页面带免责声明与置信度分级（低 / 中 / 高 / 无法判断）。

03 架构
◫ 架构图占位 — 拍照 → Qwen-VL 识别 + 离线规则引擎 → 不确定性校准 → 安全结论 + RAG 引用。
04 亮点
  • 离线规则引擎 + SVG 实时形态渲染
  • 分级不确定性表达，杜绝绝对化表述
  • 带引用的安全知识 RAG 问答
  • 全站免责声明
05 结果
  • 规则引擎只输出校准后的不确定性分级（低 / 中 / 高 / 无法判断），置信度上限 97%；性状不足 3 项强制"无法判断"；绝对化的可食用/有毒表述被测试禁止。
  • 26 条精编安全知识库（逐条标注来源）；qwen-vl-plus 拍照识别并优雅降级离线（真实端到端冒烟已验证）。
