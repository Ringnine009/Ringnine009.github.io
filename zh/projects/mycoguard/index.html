01 问题

野外采蘑菇存在真实的公共健康风险，而多数消费级“识别”工具给出过度自信的结论——一次错误的“安全”判断可能造成危险。

应用需支持野外离线使用，并诚实地表达不确定性。

02 方法

双信号通路：确定性离线规则引擎 + SVG 实时形态渲染，以及 Qwen-VL 拍照识别；两者汇入统一的不确定性校准输出。

安全知识 RAG 模块以带引用的方式回答追问；每个页面带免责声明与置信度分级（低 / 中 / 高 / 无法判断）。

03 架构
04 亮点
  • 离线规则引擎 + SVG 实时形态渲染
  • 分级不确定性表达，杜绝绝对化表述
  • 带来源的内置安全知识问答
  • 全站免责声明
05 结果
  • 规则引擎由真实 UCI 蘑菇数据集（8124 行）上训练的随机森林蒸馏而来：留出集准确率 100.00%（如实标注为教学数据集属性），Gini 重要性（气味 0.161、菌褶颜色 0.112、菌褶大小 0.111、孢子印 0.093、菌环类型 0.070）驱动权重；每条 100% 纯度分支编码为可解释规则并标注支持样本数。
  • 只输出校准后的不确定性分级（低 / 中 / 高 / 无法判断），置信度上限 97%；性状不足 3 项强制"无法判断"；绝不输出绝对化的可食用/有毒结论。
  • 规则引擎与视觉模型双通道置信度融合，带一致 / 部分一致 / 分歧指示；离线专家解读确定性生成。
06 演示

录屏：逐项选择关键性状（菌盖颜色、孢子印、菌褶大小、菌盖形状——SVG 蘑菇实时变化）→ 校准后的风险结论与免责声明 → AI 增强的安全知识问答。规则引擎全程离线运行。

07 技术栈
  • 前端：React 19 · TypeScript · Vite
  • 视觉：Qwen-VL 拍照识别
  • 知识：精编安全语料 + 关键词检索
  • 离线：纯前端规则引擎 + SVG 渲染
