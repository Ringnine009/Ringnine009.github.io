01 问题

学生针对公开教材提问，通用聊天机器人却常常幻觉——无法把答案锚定到真实教材内容。

答案必须可验证：每个论断都应能回溯到教材原文片段。

02 方法

完整 RAG 管线：解析 PDF 章节 → 结构感知分块 → BGE-M3 本地向量化（零 API 成本）→ ChromaDB 存储 → 稠密 + BM25 混合检索。

BGE 重排器对候选重新打分；DeepSeek 生成带引用的回答；检索评测集（命中率 + 答案质量）跟踪回归。

03 架构
04 亮点
  • BGE-M3 本地向量化 — embedding 零成本
  • 混合检索：稠密 + BM25，再经 BGE 重排
  • 回答带引用，可回溯到原文片段
  • 检索命中率与答案质量评测集
05 结果
  • 50 题评测集（165 节、3439 chunks）的双口径诚实检索基准：严格章节级 hit@1 = 0.82（纯稠密最优）、混合 + BM25 = 0.76；宽松口径（含关键词命中）混合 hit@1 = 0.98。两组数字都如实报告——严格口径才是诚实的主数字。
  • 答案质量：12 条抽样人工评分 4.92/5；SSE 流式与带引用来源端到端验证（如 LSTM 问题全部命中 LSTM 章节）。
  • BGE-M3 本地向量——检索零 API 成本；DeepSeek 生成带引用回答，来源高亮可溯源。
06 演示
07 技术栈
