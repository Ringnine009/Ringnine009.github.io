01 演示

完整流程：演示批次实时加载 → 带置信度的结果 → 发票详情抽屉 → 审计告警 → 趋势与规则统计图 → 交互式知识图谱。

02 问题

人工票据审核慢且易错：重复发票号漏检、金额与税率不一致难发现；OCR 工具只输出文本，没有结构也没有置信度。

03 方法

Qwen-VL 抽取结构化字段并输出逐字段置信度；声明式规则引擎审计重复、算术、税率与购销方；交互式知识图谱可视化整批票据。

04 架构
05 亮点
  • 结构化字段抽取，带逐字段置信度信号
  • 声明式规则引擎：重复 / 算术 / 税率异常
  • 交互式知识图谱探索——对象筛选、节点聚焦、关系图例
  • 发票详情抽屉：置信度条、审计证据、图谱关联
  • 审计统计图（按规则 / 按严重级）
06 结果
  • 30 张合成发票真实 API 基准（qwen-vl-plus）：字段级准确率 82.5%——发票号 86.7%、日期 90.0%、购销方 86.7%、金额 80–86.7%、税号 70–72%；平均置信度 ~0.97。
  • 8 条带严重级与证据的审计规则，含二维码交叉校验与 GB 32100-2015 税号修复；注入异常的演示批次精确产出对应告警。
07 技术栈
  • 后端：Python · FastAPI（分层架构）
  • 视觉：Qwen-VL 多模态文档理解
  • 前端：React · TypeScript 看板
  • 数据：知识图谱 + 字段级评测框架
