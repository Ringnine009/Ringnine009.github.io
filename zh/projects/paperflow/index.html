条论断经引文对照核实（本人论文）
01 演示

真实运行的现场录制：提交本人狼人杀论文 DOI → 四智能体团队（Researcher → Reader → Critic → Synthesizer）执行，任务板状态实时可见 → 结构化审阅 → 逐条引文核验视图（每条引文由代码对照原文，含位置与上下文）。

02 问题

一篇论文链接需要变成结构化审阅与相关工作链接——人工耗时数小时，结果还难以核验。

03 方法

自研轻量编排层：Researcher 通过免费 arXiv API 获取元数据，Reader 提取论断，Critic 提出质疑，Synthesizer 综合为结构化报告。

DeepSeek function calling 驱动工具调用；JSON 任务板让团队进度可检查、可复现。

04 架构
05 亮点
  • 自研轻量多智能体编排（不依赖重型框架）
  • 免费 arXiv API 集成，Crossref 兜底
  • DeepSeek function calling + JSON 任务板
  • 确定性引文核验视图——引文位置与上下文，由代码判定
  • 输出结构化审阅 + 相关工作综述
06 结果
  • 两份存档的端到端运行：本人的狼人杀论文（DOI + 本地 PDF）每条论断均与原文逐字引文配对核验，相关工作链接解析为真实 arXiv 文献；Attention Is All You Need 第二次运行走通 arXiv 全链路（正确复述 BLEU 28.4/41.8），相关性按明确评分细则评 4/10。
  • 自研编排 + 可检查的 JSON 任务板；拿不到全文时优雅降级为摘要审阅。
07 技术栈
  • 编排：自研智能体团队 + JSON 任务板
  • LLM：DeepSeek function calling
  • 数据：arXiv API（+ Crossref/doi.org 兜底）
  • 语言：Python
